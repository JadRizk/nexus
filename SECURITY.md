# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities using [GitHub's private vulnerability
reporting](https://github.com/JadRizk/nexus/security/advisories/new) for this
repository, rather than opening a public issue.

Private reporting lets a maintainer see the details, ask follow-up questions,
and coordinate a fix before anything is disclosed publicly.

If private reporting is not available to you for some reason, open a regular
issue asking a maintainer to enable it or to provide another contact path —
without including the vulnerability details in that issue.
