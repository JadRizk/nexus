Agent protocol

This board is the queue. A Claude session working on the Nexus repository takes a ticket here, works it in the repo, and reports back here. Humans and agents use the same store, so what you see is what every agent sees. The store is the artifact database, reached from a Claude Code session with the Artifact tool's read_db and write_db actions against this page's URL.

  1. Find a ready ticket. A ticket is ready when its status is todo and every id in its blockedBy list has status done. Prefer the lowest order in the lowest gate.
  2. Claim it before touching the repo: set status to in_progress, assignee to your session name, and append a log entry. If another assignee is already set and the ticket is in progress, pick a different one.
  3. Work it in a branch named after the ticket, e.g. nx-07-drawer-trap. Do everything under "What needs to be done". Run the repo's own checks (lint, typecheck, test, build, check-docs) before you report.
  4. Report. Tick the acceptance criteria you verified, set status to review, add a log entry naming the branch or pull request. Do not mark done yourself; a reviewer moves it.
  5. Blocked? Leave status in_progress, add a log entry saying what you are waiting on, and clear assignee if you are abandoning it.
